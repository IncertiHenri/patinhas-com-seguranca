# Aplicação de CRUD na atividade AUmigos

A AUmigos é uma pet shop que realiza serviços de banho, tosa, consultas e outros cuidados para animais de estimação.Atualmente, os dados dos clientes e de seus animais são registrados de forma desorganizada, dificultando o controle dos pets atendidos pela empresa. Para solucionar esse problema, você foi contratado para desenvolver um sistema web para realizar o cadastro e gerenciamento dos clientes e seus animais. A AUmigos precisa saber quem é o responsável pelo animal e quais animais pertencem a cada cliente.

## Desafio

Desenvolver um sistema simples para o cadastro de animais e usuários, que permita cadastrar, editar, visualizar e excluir em qualquer momento. 

## Desenvolvimento

Utilizamos o XAMPP, VS code e o GitHub.
